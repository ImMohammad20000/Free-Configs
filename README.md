## توضیحات

پروژه‌های خوبی وجود دارند که کانفیگ‌های رایگان vless/trojan/vmess را از منابع مختلف جمع‌آوری و تست می‌کنند. این پروژه هم از همان منابع استفاده می‌کند، با این تفاوت که هر کانفیگ را با یک درخواست واقعی proxy-شده (نه صرفاً پینگ یا تست اتصال TCP) و در سه دور مستقل تست می‌کند؛ فقط کانفیگ‌هایی که در هر سه دور سالم باشند منتشر می‌شوند.

کانفیگ‌های نهایی دقیقاً همان‌طور که از منبع اصلی دریافت شده‌اند منتشر می‌شوند — هیچ تنظیمی (آدرس، پورت، امنیت، fingerprint و غیره) تغییر داده نمی‌شود، فقط تکراری‌ها حذف و کانفیگ‌های ناسالم فیلتر می‌شوند. بنابراین با هر کلاینت استاندارد v2ray/xray قابل استفاده هستند.
